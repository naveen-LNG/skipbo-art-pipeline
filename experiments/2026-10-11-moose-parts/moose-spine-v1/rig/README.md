# Moose Spine rig (generated, v2)

Generated by `plugin/skills/skipbo-art/scripts/spine_rig.py`; checked with `spine_qa.py` (all checks PASS, setup IoU 0.976).

- **Import into Spine:** Import Data → `moose.json` (Spine 4.2). Images load from `./images/`.
- **Preview without Spine:** `python3 -m http.server 8765 --directory .`, then open `http://localhost:8765/preview.html`.
  - Add `?anim=wave&t=0.7` to freeze a frame.
  - Add `&bones=1` to show the bones.
- **QA output:** `qa/<anim>.gif` (every frame), `qa/<anim>_strip.png`, `qa/setup_vs_master.png`, `qa/report.json`.

## Structure
- **21 bones.**
  - root → hips → torso → head_base (antlers, ears, cap).
  - torso → scarf → bell.
  - torso → upperarm → forearm → hand, on each side.
  - hips → leg → hoof, on each side.
- **Cut from the master** (exact proportions, round caps at the joints): arms, hands, legs, hooves, hips.
- **Generated parts** (their hidden areas are painted in): torso, head, cap, antlers, ears, scarf, bell.
- **Head slot:** 9 expression heads plus `head_base`; `moose_head_neutral` is the default.
- **`torso_patch`:** master vest-edge pixels the generated torso didn't reach. It's static on the torso bone.

## Animations
Keys are at 30 fps with eased starts and stops.

| Animation | What happens |
|---|---|
| `idle` | 2.4 s seamless loop: breathing, head bob, arm, antler and ear sway, one blink |
| `wave` | 3.0 s: left arm rises, forearm waves twice, arm lowers; happy face throughout |
| `cheer_jump` | 1.9 s: squash, jump (12% of height), arms up into a V clear of the antlers, fist pumps, soft landing, recover |
| `blink` | Single blink |
| `emotions` | Cycles all 9 heads |

## Rough edges for the rigger
- The texture inside the round joint caps rotates with the limb. That's invisible on plain sleeves, but noticeable on a patterned sleeve at large bends.
- The wave is set to a target pose for this front-view rig. Other actions need hand-animating in Spine; the bones and pivots are ready for it.
