Caveats worth knowing

  • The server keeps only about three days of job history (611 entries, 8–11 Oct). Everything earlier is reconstructed from save counters, not job records, so the prompts and seeds behind the August and September generations are gone from the server.
  • 911 is a lower bound. It counts only the 35 output prefixes recoverable from transcripts; the earlier Event Automator era wrote to eventautomator/ and those files have been purged (the probe returns nothing).
  • “Image” here means a prompt cluster, not a finished asset. A finished asset — the Moose — consumed 104 generations, roughly 36× the per-cluster average, because every body part, face patch and pose is its own cluster.
  • Cut-out passes (RMBG-1.4) are counted separately throughout. They use the same server but generate no new imagery.
  • The 2.9 average covers the 8–11 Oct window only, which was character-rig work. That iterates harder than icon work, so an icon-heavy week would average lower.
